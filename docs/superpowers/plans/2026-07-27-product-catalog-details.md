# Product Catalog Details Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add concise, native, accessible expandable details to all 54 catalog products while preserving every existing product identity, family, order, filter, search behavior, and responsive layout.

**Architecture:** Keep the catalog as static typed data inside `CodeDreamersLanding.tsx`, extending each product with one description and a fixed three-item tuple. Render each row with independent native `<details>/<summary>` markup so multiple rows can remain open without React state or JavaScript-driven closing; use existing family-color styling plus a CSS-only opening animation, never the experimental `::details-content` pseudo-element. Add one Vitest data-contract test and no general refactor.

**Tech Stack:** React 19.2, TypeScript 5.9 in strict mode, Vite 8, Vitest 4, semantic HTML `<details>/<summary>`, CSS media queries.

## Existing Patterns

- `src/CodeDreamersLanding.tsx:22-136` already keeps catalog data in one typed `families` constant; this plan extends that data in place rather than introducing a store or data layer.
- `src/CodeDreamersLanding.tsx:658-790` already derives filtered families with `useMemo`; this plan leaves that logic unchanged so queries continue to match product code and name only.
- `src/styles.css:1229-1275` already uses family accents, explicit `:focus-visible`, and short transitions on product rows; the new summary follows those conventions.
- `src/styles.css:2622-2649` already makes all transitions and animations effectively immediate under `prefers-reduced-motion: reduce`; the opening keyframe and arrow transition inherit that behavior.
- No existing native `<details>/<summary>` pattern exists in this source. The new markup deliberately uses browser semantics rather than introducing component state, an exclusive accordion, or a custom ARIA disclosure.
